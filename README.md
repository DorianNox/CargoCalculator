🚛 КаргоМаршрут — Калькулятор стоимости доставки

Веб-приложение для расчёта цены транспортировки грузов с системой лояльности, промокодами и историей заказов.


📦 О проекте
КаргоМаршрут — это одностраничное веб-приложение (single HTML file), которое позволяет пользователям рассчитать стоимость доставки груза на основе его габаритов, веса, расстояния и срочности. Данные хранятся локально в браузере через localStorage — никакого бэкенда не требуется.

✨ Функциональность
🧮 Калькулятор доставки

Ввод длины, ширины, высоты груза (в сантиметрах)
Ввод веса (кг) и расстояния (км)
Расчёт через объёмный вес по стандартной логистической формуле L × W × H / 5000
Итоговая цена = максимум из фактического и объёмного веса
Надбавка за погрузку: +100 ₽ за каждые 50 кг
Минимальная стоимость доставки: 350 ₽
Подробная разбивка цены в интерфейсе

🎖️ Система лояльности
УровеньЗаказовСкидка🆕 Новичок0—🎉 Первый заказ1−25%⭐ Постоянный2–4−10%💎 Серебро5–9−20%👑 VIP10+−40%
🎟️ Промокоды

WELCOME25 — выдаётся при регистрации, скидка 25%, срок 30 дней
LOYAL10 — автоматически после 3-го заказа, скидка 10%
SILVER20 — после 5-го заказа, скидка 20%
VIP40 — после 10-го заказа, скидка 40%
В профиле отображается статус каждого промокода: активен / использован / истёк

📋 История заказов

Хранится до 15 последних заказов
При превышении лимита — самый старый заказ удаляется автоматически (FIFO)
Отображается дата, габариты, вес, расстояние, срочность и итоговая цена

📐 Формула расчёта цены
Объёмный вес (кг)   = Длина × Ширина × Высота / 5000
Расчётный вес (кг)  = max(фактический вес, объёмный вес)
Базовая цена (₽)    = max(расчётный вес × расстояние × 0.04 + надбавка, 350)
Итоговая цена (₽)   = базовая цена × коэф. срочности × (1 − скидка лояльности) × (1 − промокод)
